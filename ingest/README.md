# ingest/ — manual source drops (rung 2 of the ladder)

If YouTube blocks the machine's downloads (bot-check) and cookies
can't fix it, drop real Fortnite map gameplay MP4s here. The machine
mines clips from them and clears the folder.

Rules:
* Any real gameplay MP4/MKV, ideally 720p+, 2 minutes or longer.
* Named anything — the machine takes the oldest file first.
* The file is CONSUMED (deleted) after a clip is mined from it.
